HTML fácil para principiantes

HTML es el lenguaje que se usa para crear páginas web. Con HTML le dices al navegador qué mostrar: títulos, párrafos, imágenes y enlaces.

La estructura más simple

Un archivo HTML siempre tiene estas partes:

  • Doctype: avisa que el archivo es HTML.
  • html: contiene todo el contenido de la página.
  • head: es información de la página, como el título.
  • body: es lo que se ve en la página.
<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8">
    <title>Mi página fácil</title>
  </head>
  <body>
    <h1>Hola</h1>
    <p>Esta es mi primera página web.</p>
  </body>
</html>

Textos básicos

Estas etiquetas muestran texto:

  • <h1> a <h6>: títulos de diferentes tamaños.
  • <p>: un párrafo.
  • <strong>: texto en negrita.
  • <em>: texto en cursiva.

Enlaces

Un enlace lleva a otra página o a otro lugar.

<a href="https://www.google.com" target="_blank">Ir a Google</a>

Imágenes

Para poner una imagen necesitas su dirección y un texto alternativo.

<img src="imagen.jpg" alt="Descripción de la imagen">

Listas

Hay dos tipos de listas:

  • <ul>: lista con viñetas.
  • <ol>: lista numerada.
  • <li>: cada elemento de la lista.
<ul>
  <li>Manzana</li>
  <li>Plátano</li>
</ul>

Algunas palabras importantes

  • id: nombre único para un elemento.
  • class: etiqueta para agrupar elementos.
  • href: dirección de un enlace.
  • src: dirección de una imagen o archivo.
  • alt: texto que describe una imagen.

Resumen

HTML es el lenguaje para crear la estructura de una página web. Con etiquetas simples como <h1>, <p>, <a> e <img> puedes construir una página muy rápido.

Practica escribiendo tu propio archivo HTML y abre el navegador para ver el resultado.
